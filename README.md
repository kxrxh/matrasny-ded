# Матрасный дед

Просто матрасный дед.

![Матрасный дед](preview.webp)

Отправь Codex один промпт:

```text
Установи питомца из https://github.com/kxrxh/matrasny-ded: скачай pet.json и spritesheet.webp из ветки main в папку pets/matrasny-ded внутри CODEX_HOME (по умолчанию ~/.codex). Перед заменой существующей папки сохрани её резервную копию. В конце напомни нажать Refresh в Settings → Pets.
```
